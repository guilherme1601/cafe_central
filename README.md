Projeto Café Central

Objetivo do Projeto
O site Café Central tem como objetivo divulgar seus produtos e facilitar o contato com os clientes por meio de um site institucional autoral, fortalecendo a identidade da marca.

## Público-alvo
Todas as idades.

## Páginas Institucionais
1. Menu
2. Cardápio
3. Chat com o Cliente
4. Feedback
5. Sobre Nós

## Requisitos Funcionais
- Exibir a localização da loja.
- Exibir todos os produtos oferecidos no cardápio.
- Disponibilizar contato com a loja.
- Garantir navegação funcional entre as páginas.

## Requisitos Não Funcionais
- Layout organizado e intuitivo.
- Código HTML semântico, legível e indentado.
- Compatibilidade com navegadores modernos.
- Compatibilidade com múltiplas plataformas.

## Requisitos Estruturais
- Menu de navegação presente em todas as páginas.
- Estrutura de pastas padronizada.

## Organização do Ambiente de Desenvolvimento
- IDE utilizada: Visual Studio Code.
- Pasta raiz do projeto: `Cafe-central`.
- Padrão de nomenclatura aplicado (letras minúsculas e sem espaços).
- Projeto organizado com separação entre HTML, CSS e JavaScript.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript
- Visual Studio Code

## Como Executar a Aplicação
1. Clone ou faça o download do repositório do projeto.
2. Abra a pasta `Cafe-central`.
3. Abra o arquivo `index.html` em um navegador de sua preferência.

O projeto pode ser executado utilizando a extensão **Live Server** do Visual Studio Code para facilitar o desenvolvimento
